# One Word for the Boss

My word for the boss: **Buzzwordsmith**.

## Why this word

Every office has one: the boss who never just says "let's do it". Instead it's
"let's circle back and leverage our synergies to move the needle on this
bandwidth-constrained deliverable." A buzzwordsmith doesn't manage, they
*orate* — fluent in words that sound important and mean nothing, while the
actual work waits for someone to translate the meeting back into English.
You have met this boss. You have nodded along in a meeting while doing that
translation in your head. That is why the word lands: funny because it's true,
and true because it's every meeting you've ever sat through.

## How it works

`main.py` (pure Python standard library, no third-party imports) validates the
word — exactly one word, 1–30 characters, no whitespace — then writes it with
no trailing newline to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (falling back to
`/output`), file mode `0644`. Run it:

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
cat output/entry.txt   # Buzzwordsmith
```
